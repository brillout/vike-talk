## Title

[Next.js/Nuxt alternative] The composable framework — build advanced applications with stability and flexibility.

## Description

Frameworks regularly introduce breaking changes with radically different approaches, forcing large projects into years-long migrations. Innovation requires disruption — but can a framework provide a stable foundation while fostering innovation?

Vike is built on a stable, rock-solid core with powerful low-level hooks. This offers unprecedented flexibility (and room for innovation) — alongside unprecedented stability.

Rom will show Vike's:
- Architecture (stable core with powerful extensions)
- Use cases (how Burda uses Vike for focus.de, chip.de, bunte.de, and eventually all their brands)
- DX (first-class SPA/SSR/SSG, RPC, file-based server/client separation, next-gen scaffolder)
- Business model (100% open source, 100% gratis for engineers, asking larger companies to contribute)
- Future (of web frameworks)
