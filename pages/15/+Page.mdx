# Use case Burda

Burda GmbH owns [focus.de](https://www.focus.de), [chip.de](https://www.chip.de), [bunte.de](https://www.bunte.de), ...

- Solid (React alternative) + SSR
- **Before**: fragmented stacks  
  => cannot impove all websites at once
- **Now**: Internal company framework powering all websites  
  => Software Architects controls architecture of all websites  
  => App code: product developers
- **Vike core**, without any Vike extension  
  => full control over architecture + rock-solid foundation  
- `vike-react` is ~1k LoC => easy to build your own framework
