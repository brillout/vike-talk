## Custom integration

✅ Full control  
👎 Lot's of integration & boilerplate code — okay for simple apps  
❌ No-go for some apps (you'd essentially re-create a framework)  

## Framework

👍 Minimal boilerplate code  
👍 SSR/SPA/SSG toggles  
👍 Data-fetching  
👍 Client-side routing & pre-fetching  
👍 Code-splitting  
👍 HTML streaming  
...  

😕 No control (bad with some frameworks => "framework slave")
