# SSR vs SSG

SSG: pre-render the HTML of pages at build-time  
  => no production server required ✅

Recommendation: use SSG whenever possible.

❌ SSG isn't an option for frequently changing content.

- Landing page => SSG or SSR?
- `reddit.com` => SSG or SSR?
